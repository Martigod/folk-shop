-Folk Shop
Учебен проект по Интернет базирани технологии
Проектът представлява онлайн магазин за фолклорно облекло
*Използвани технологии
-HTML
-CSS
-JavaScript
-Node.js
-Express.js
-MongoDB
-Mongoose
*Основни функционалности
-Начална страница с продукти
-Детайлна страница за всеки продукт
-Обща количка
-Изпращане на поръчка
-Записване на поръчките в MongoDB
-Изпращане на ревю
-Записване на ревютата в MongoDB
-Административен панел
-Преглед на поръчки
-Добавяне на продукти
-Редактиране на продукти
-Изтриване на продукти
-Показване колко пъти е закупен всеки продукт
*Стартиране на проекта
-Първо трябва да се инсталират зависимостите с npm install
-След това се свързва с MongoDB с адрес: mongodb://127.0.0.1:27017/folk-shop
-След това се добавят продукти в басата с node seed.js
-След това се стартира съвърът с node app.js и проектът се отваря на http://localhost:3000
*Описание на страниците
-index:
Начална страница
-product:
обща страница за описание на продуктите и включва име, снимка, описание, ревюта бутон за добавяне в количката
-cart:
Показва всички продукти в количката и може чрез форма да изпрати продуктите
-admin:
Административен панел
*Описание на MongoDB колекции
-products:
пази се всичко за продукта
-orders:
пазят се поръчките и всичко за тях(продукта, купувача и бройката)
-reviews:
включва продукта, коментара за продукта и дата на създаване
